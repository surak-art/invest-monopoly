INVEST MONOPOLY GAME — VERSION 3.0 (CAUSAL MARKET SIMULATION)
============================================================

สิ่งที่เพิ่มในเวอร์ชันนี้
-------------------------
1) โหมดห้องเรียน: ครูใช้คอมพิวเตอร์เครื่องเดียว เพิ่มชื่อกลุ่มได้ตามจำนวนนักเรียน/กลุ่ม
   เปิดไฟล์ public/classroom.html ผ่านเว็บเซิร์ฟเวอร์เดียวกัน แล้วควบคุมเกมจากเครื่องครู
2) โหมดแข่งขันออนไลน์: สร้างห้องและแชร์รหัส ผู้เล่นเข้าร่วมจากอุปกรณ์ของตนเอง
   จำกัด 2–12 คนต่อห้อง ใช้ WebSocket ส่งสถานะตลาดและผลการเล่นแบบเรียลไทม์
3) ตลาดจำลองเชิงเหตุและผล: ราคาสินทรัพย์เปลี่ยนจากทั้งปัจจัยเศรษฐกิจร่วมและความผันผวนเฉพาะสินทรัพย์
   ปัจจัยร่วม ได้แก่ การเติบโตเศรษฐกิจ เงินเฟ้อ อัตราดอกเบี้ย ความเสี่ยง และราคาพลังงาน
4) แสดงราคาตลาดปัจจุบันและกำไร/ขาดทุนที่ยังไม่เกิดขึ้นจริง (unrealized P/L)
   การขายจะใช้ราคาตลาด ณ ขณะนั้น ไม่ใช่ราคาขายคงที่

ความสัมพันธ์ที่ใช้ในเกม (แบบจำลองเพื่อการเรียนรู้ ไม่ใช่สูตรพยากรณ์ตลาดจริง)
----------------------------------------------------------------------------
- หุ้น/กองทุนหุ้น: ได้แรงหนุนจากเศรษฐกิจเติบโต และถูกกดดันจากความเสี่ยง/ดอกเบี้ยสูง
- พันธบัตร: ราคามักเคลื่อนไหวสวนทางกับอัตราดอกเบี้ยตลาด
- หุ้นกู้เอกชน: อ่อนไหวต่อดอกเบี้ยและความเสี่ยงเครดิตมากกว่าพันธบัตรรัฐบาล
- ทองคำ: อาจได้แรงหนุนจากเงินเฟ้อ ความเสี่ยงโลก และราคาพลังงาน แต่ถูกกดดันได้จากดอกเบี้ยสูง
- ที่ดิน: ได้แรงหนุนจากเศรษฐกิจและเงินเฟ้อ แต่ต้นทุนดอกเบี้ยสูงเป็นแรงกดดัน
- เงินฝาก: ผลตอบแทนจำลองต่ำและมีความผันผวนของราคาแทบไม่มี

สูตรย่อ:
ผลตอบแทนรอบนี้ = ผลกระทบจากปัจจัยเศรษฐกิจ + ความผันผวนเฉพาะสินทรัพย์
ราคาตลาดใหม่ = ราคาตลาดเดิม x (1 + ผลตอบแทนรอบนี้)
ระบบจำกัดผลตอบแทนต่อรอบไม่ให้เกิน +/-22% และปัดราคาเป็นจำนวนเต็มเหรียญ

ข่าวเศรษฐกิจที่มีผลกับตลาด
---------------------------
- มาตรการกระตุ้นเศรษฐกิจ: เพิ่มเงินสดให้ทุกกลุ่ม +10 เหรียญ และมีแรงหนุนอุปสงค์
- ความขัดแย้งระหว่างประเทศ/พลังงานแพง: เพิ่มความเสี่ยงและแรงกดดันเงินเฟ้อ
- เงินเฟ้อลดลง/ดอกเบี้ยผ่อนคลาย: ลดต้นทุนเงินทุนและช่วยให้สินทรัพย์บางประเภทฟื้นตัว
- เหตุการณ์อื่นสุ่มจากชุดเศรษฐกิจ เช่น เศรษฐกิจชะลอตัว วิกฤตเครดิต และราคาพลังงานลดลง

ข้อจำกัดและข้อควรทราบ
----------------------
- เป็นแบบจำลองการเรียนรู้ที่ตั้งใจให้เห็นความสัมพันธ์เชิงทิศทาง ไม่ใช่แบบจำลองทางการเงินที่ผ่านการสอบเทียบ
- ผลกระทบเป็นค่าจำลองในหน่วยเปอร์เซ็นต์ต่อรอบ ไม่ใช่การคาดการณ์ผลตอบแทนจริง
- ประกันภัยเป็นกลไกคุ้มครองเหตุการณ์ส่วนบุคคลตามเกม ไม่ใช่หลักทรัพย์ลงทุน
- โหมดออนไลน์เก็บห้องไว้ในหน่วยความจำของเซิร์ฟเวอร์เท่านั้น รีสตาร์ตเซิร์ฟเวอร์แล้วห้องจะหาย
- ยังไม่มีระบบบัญชีผู้ใช้ ฐานข้อมูลถาวร ระบบบันทึกผลข้ามวัน หรือการยืนยันตัวตน
- โหมดห้องเรียนเป็นระบบ local บนเครื่องครู ไม่ได้ส่งข้อมูลขึ้นห้องออนไลน์ และไม่มีเพดานผู้เล่นในหน้าตั้งค่า
- ควรทดลองเล่นและตรวจสอบกติกา/ผลตอบแทนก่อนใช้ประเมินผลนักเรียนจริง

วิธีติดตั้ง
-----------
1) ติดตั้ง Node.js รุ่น LTS
2) แตกไฟล์ ZIP
3) เปิด Terminal/Command Prompt ในโฟลเดอร์ invest_assets
4) รันคำสั่ง: npm install
5) รันคำสั่ง: npm start
6) เปิด http://localhost:3000 เพื่อเล่นออนไลน์
7) เปิด http://localhost:3000/classroom.html สำหรับโหมดครูใช้เครื่องเดียว

การเผยแพร่ให้เล่นออนไลน์
-------------------------
นำโฟลเดอร์นี้ขึ้นบริการโฮสต์ที่รองรับ Node.js และ WebSocket เช่น Render หรือ Railway
ตั้งคำสั่งเริ่มระบบเป็น npm start และใช้ PORT จาก environment ของผู้ให้บริการ
เมื่อ deploy สำเร็จ ให้แชร์ URL เว็บไซต์และรหัสห้องกับผู้เล่น

ทดสอบเบื้องต้น
--------------
รัน: node --check server.js
ตรวจสุขภาพเซิร์ฟเวอร์: เปิด /health ควรได้ {"ok":true,...}
ควรทดสอบหลายเบราว์เซอร์/หลายอุปกรณ์ก่อนใช้จริง โดยเฉพาะการเชื่อมต่อหลุดและการจบรอบ


รุ่น 3.1 — แดชบอร์ดครูและรายงานชั้นเรียน
- โหมดห้องเรียนเพิ่มแดชบอร์ดแสดงจำนวนกลุ่ม มูลค่าพอร์ตเฉลี่ย ผู้นำปัจจุบัน และจำนวนจุดข้อมูล
- เพิ่มกราฟแนวโน้มมูลค่าพอร์ตสุทธิรายรอบของแต่ละกลุ่ม
- ส่งออกรายงานผลเป็น CSV (เปิดด้วย Excel/Google Sheets ได้) พร้อมเงินสด มูลค่าสินทรัพย์ มูลค่าพอร์ตสุทธิ และข่าวเศรษฐกิจในแต่ละรอบ
- ส่งออกบันทึกเหตุการณ์เป็น TXT
- กราฟและรายงานทำงานในเครื่องครู ไม่ต้องเชื่อมต่อฐานข้อมูล
หมายเหตุ: ข้อมูลในรายงานเป็นผลจากแบบจำลองเพื่อการเรียนรู้ ไม่ใช่คำแนะนำหรือการคาดการณ์ราคาสินทรัพย์จริง
